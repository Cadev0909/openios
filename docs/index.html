Quick Start

  1. Add this repo in Sileo/Zebra
  2. Install llama-cpp-ios and cloud-ui
  3. SSH into your device and download a GGUF model:
    wget -O /var/jb/var/llama-models/active.gguf <model-url>
  4. Start llama-server:
    /var/jb/usr/local/bin/llama-server --model /var/jb/var/llama-models/active.gguf --port 8080 --n-gpu-layers 99
  5. Open Safari → http://127.0.0.1:3000
